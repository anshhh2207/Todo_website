# Zenith Studio • Next-Gen Task & Productivity Suite

A modern, glassmorphic, zero-dependency task management and productivity web application built with semantic HTML5, modern vanilla CSS3, and ES6+ JavaScript.

---

## 🚀 Quick Start

The local web server is already active:
- **Local URL:** [http://localhost:3000](http://localhost:3000)
- Or simply double-click [index.html](file:///d:/github/index.html) in your browser.

---

## ✨ Features

- **Hyper-Aesthetic Glassmorphism UI**: Ambient moving glows, smooth gradients, subtle borders, and modern typography (`Plus Jakarta Sans` & `JetBrains Mono`).
- **Dark & Light Mode**: Seamless dynamic theme switching with persistent user preference.
- **Analytics & Goal Tracking**:
  - Live animated SVG completion ring displaying progress percentage.
  - Metrics cards: Total active tasks, tasks due today, and completed milestones.
  - Daily completion streak counter 🔥.
- **Task Management**:
  - Task title, multi-line notes/descriptions, priority tags (`Urgent`, `High`, `Medium`, `Low`), and due dates with smart relative badges (`Today`, `Tomorrow`, `Overdue`).
  - Interactive subtasks checklist with individual progress tracking.
  - HTML5 Drag-and-drop reordering.
- **Filter & Organization**:
  - Sidebar smart views: *All Tasks*, *Today*, *Upcoming*, *Important*, and *Completed*.
  - Custom color-coded project/category tags (*Work*, *Personal*, *Projects*, *Health*, *Learning* + custom tag creation).
  - Real-time global search (`/`) and multi-criteria sorting (by due date, priority, date added, or name).
- **Interactive Delights**:
  - Built-in lightweight Canvas Confetti engine on task completion.
  - Synthesized audio feedback via Web Audio API (crisp completion chime & subtle clicks, toggleable).
  - Integrated Pomodoro focus timer (25m focus / 5m break) in the sidebar.
  - Undo deletion notification toast.
  - Full JSON backup export and import.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>N</kbd> | Focus new task creation input |
| <kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd> | Focus global task search |
| <kbd>T</kbd> | Toggle Dark / Light theme |
| <kbd>P</kbd> | Toggle Pomodoro focus timer |
| <kbd>?</kbd> | Open Keyboard Shortcuts cheatsheet |
| <kbd>Esc</kbd> | Close any open modal or blur inputs |
